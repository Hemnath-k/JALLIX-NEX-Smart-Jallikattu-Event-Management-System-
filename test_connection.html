📋 Troubleshooting Guide

If you see "Method Not Allowed":

  • ✅ You must use http://localhost:8080/test_connection.html
  • ❌ NOT file:///D:/Jallikattu/test_connection.html

Correct Way to Access:

  1. Start the frontend server: python -m http.server 8080
  2. Open: http://localhost:8080/test_connection.html
  3. NOT by double-clicking the HTML file!
